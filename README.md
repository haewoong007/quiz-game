# quiz-game

상식 퀴즈 게임 앱. 2차 구현 실습용 저장소다.

## 배포 주소

| 단계 | 주소 |
|---|---|
| 2차 구현 1단계 | https://quiz-game-gamma-bay.vercel.app |

프로덕션 주소는 늘 최신 프로덕션 배포를 가리킨다. 단계별로 그 시점을 다시 열어야 하면 태그를 쓴다.
